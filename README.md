# 盤點班表調移系統

排班人員匯入 Excel 班表，以拖曳方式調整門市與人員配置，再匯出回 Excel。
系統會自動偵測「排班次數過多」「休假卻被排班」「同一間店排兩次」等問題。

**React 19 + Vite 8 + Tailwind CSS 4 · 純靜態 SPA · 無資料庫 · 不寫入任何資料**

---

## 接手者要做的事

**串接兩支唯讀 GET API。** 其餘功能前端皆已完成，不需後端參與。

| API | 用途 |
|---|---|
| `GET /api/staff/roster?dept=北一課` | 人員通訊錄（姓名、職稱、班表代號） |
| `GET /api/staff/leave?dept=北一課&yearMonth=202608` | 人員休假日期與假別 |

**唯一需要修改的檔案：** [`src/services/staffApi.js`](src/services/staffApi.js)（待串接處皆有 `// TODO` 標註）

呼叫時機在 `src/App.jsx` 的 `useEffect`，班表匯入後自動觸發，一般不需修改。
API 位址於 `.env` 設定 `VITE_API_BASE_URL`，未設定時預設 `/api`。

## 修改前務必確認

以下幾點已用 390 筆實際資料驗證，變更前請先閱讀對應章節，避免破壞既有正確行為。

- **請勿更動「人力」與「盤點1～8」的欄位歸屬。**
  這兩者屬於**人員**資料而非門市資料，拖曳互換人員時必須跟著人一起移動。
  此處原本有 bug（歸類為門市），導致互換後工號對錯人，v1.1.0 已修正。詳見 SDD 3.2。

- **請勿假設每日固定 30 列以支援其他格式的班表。**
  現行解析僅適用「每日 15 組 × 上下午 = 30 列」的匯入格式。
  另一種「盤點行事曆報表」格式（午別為上／下、每日筆數 2～21 不等）尚未支援，
  分組規則待業務端確認後再實作。詳見 SDD 9。

- **「代號 → 工號」與「店號 → 門市資料」對照表由班表自行推導，不需 API 提供。**
  通訊錄 API 的價值在於姓名、職稱與完整名單，而非工號。詳見 SDD 3.3。

- **出勤統計僅計算「店號有填」的槽位。**
  班表中店號空白的列常用來記錄業務備註（如「效期 青+2PT」），一併統計會產生大量雜訊。詳見 SDD 3.6。

## 快速試用

`可直接開啟/盤點班表調移系統.html` 點兩下即可用瀏覽器開啟，不需安裝任何東西。

## 如何執行

### 方式一：免安裝單一檔案

`可直接開啟/盤點班表調移系統.html` 已把 JS 與 CSS 全部內嵌，可直接開啟或郵件寄送。

重新產生：

```bash
npm run build:standalone
```

產物在 `dist-standalone/index.html`。

> 一般建置產物無法用 `file://` 直接開啟——Chrome 會以 CORS 政策擋下外部 ES module，
> 畫面會空白。因此此版本將所有資源內嵌以避開該限制。

### 方式二：開發模式

```bash
npm install
```

```bash
npm run dev
```

### 方式三：部署到伺服器

```bash
npm run build
```

產物在 `dist/`，可放上任何靜態主機。

> `vite.config.js` 的 `base` 預設為 `/MOVE/`（原開發環境的路徑）。
> **部署到其他位置時務必修改**：部署於網站根目錄請設為 `'/'`，
> 部署於子目錄請設為該子目錄路徑，或設為 `'./'` 使用相對路徑。

**API 尚未完成也能跑** — 畫面會顯示「人員資料 API 尚未連線」提示，但班表匯入、
拖曳調移、槽位編輯、匯出、店暫存區、門市重複警告全部正常運作。
建議先跑起來看實際畫面，再決定 API 怎麼實作。

## 功能總覽

- **班表匯入**：支援點選或拖曳 Excel 檔；標題列位置與欄位皆動態偵測，未知欄位原樣保留
- **拖曳調移**：門市↔門市、人員↔人員互換；店暫存區與班表槽位雙向拖曳（覆蓋時原門市自動退回暫存區）
- **店暫存區**：手動新增門市或匯入店庫異動 Excel；可指定日期，限定該店只能排在特定日
- **自動對照**：由班表推導「代號↔工號」與「店號↔門市資料」，編輯時自動同步人力、工號、課別代號與營業課別
- **當日出勤列**：依當日排班次數上色（無色未排班／淡藍休假／黃1間／綠2間／紅需留意）
- **休假衝突警告**：已休假卻被排班時，於上方列出姓名、假別與所在組別
- **門市重複偵測**：整份班表掃描重複排班的門市，橫幅列出並可點擊跳轉（僅警告不阻擋，轉換店可能需盤第二次）
- **班表匯出**：欄位順序與每日 30 列格式完全還原

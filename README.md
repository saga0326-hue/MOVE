# 盤點班表調移系統（INV-SHIFT）

排班人員匯入盤點行事曆勤務報表，以拖曳方式調整門市與人員配置，再匯出回 Excel。
系統會自動偵測「排班次數過多」「休假卻被排班」「同月重複盤點」等問題。

**React 19 + Vite 8 + Tailwind CSS 4 · 純靜態 SPA · 無資料庫 · 不寫入任何資料**

---

## 接手者要做的事

**串接三支唯讀 GET API。** 其餘功能前端皆已完成，不需後端參與。

| API | 用途 | 實作位置 |
|---|---|---|
| `GET /api/staff/roster?dept=北一課` | 人員通訊錄 | `src/services/staffApi.js` |
| `GET /api/staff/leave?dept=北一課&yearMonth=202608` | 人員休假 | `src/services/staffApi.js` |
| `GET /api/stores?dept=北一課` | 店鋪檔 | `src/services/storeApi.js` |

待串接處皆有 `// TODO` 標註。呼叫時機在 `src/App.jsx` 的 `useEffect`，
班表匯入後自動觸發，一般不需修改。API 位址於 `.env` 設定 `VITE_API_BASE_URL`，
未設定時預設 `/api`。

**API 尚未完成也能跑** — 畫面顯示提示並降級，班表匯入、拖曳調移、就地編輯、
匯出、店暫存區、重複盤點警告全部正常運作。

## 修改前務必確認

以下皆已用實際資料驗證，變更前請先閱讀對應章節，避免破壞既有正確行為。

- **請勿更動欄位歸屬。**
  「人力」與「盤點1～8」屬**人員**（隨人員移動）；「備註」屬**門市**（隨門市移動）。
  兩處都曾歸類錯誤，導致互換後工號對錯人、備註與門市脫勾。詳見 SDD 3.2。

- **請勿以「序」排序。**
  該欄是全域流水號，依它排序會把同組人員完全打散（實測：檔案順序 215 組全部相鄰，
  依序排序完全打散）。一律依檔案原始順序。詳見 SDD 5.1。

- **分組必須在匯入時固定，不可即時重算。**
  分組依「預定盤點者首字」判定，若隨內容重算，使用者一改人員卡片就會跳位置。
  詳見 SDD 5.3。

- **對照表必須在匯入時建立並凍結。**
  若依當前資料重算，門市被移到暫存區後即從主檔消失，重新輸入店號會查不到。
  詳見 SDD 6。

- **出勤統計僅計算「店號有填」的列。**
  店號空白的列常用來記錄業務備註，一併統計會產生大量雜訊。詳見 SDD 7.7。

- **匯出時「序」保留原值、「人力」重算、空白列不輸出。**
  詳見 SDD 7.9。

## 如何執行

### 方式一：免安裝單一檔案（發給使用者）

```bash
npm run build:standalone
```

產物在 `dist-standalone/index.html`，JS 與 CSS 全部內嵌，可直接開啟或郵件寄送。

> 一般建置產物無法用 `file://` 直接開啟——Chrome 會以 CORS 政策擋下外部 ES module，
> 畫面會空白。因此單檔版本將所有資源內嵌以避開該限制。

### 方式二：開發模式

```bash
npm install
```

```bash
npm run dev
```

### 方式三：部署到伺服器

```bash
npm run build
```

產物在 `dist/`，可放上任何靜態主機。

> `vite.config.js` 的 `base` 預設為 `/MOVE/`（原開發環境的路徑）。
> **部署到其他位置時務必修改**：部署於網站根目錄請設為 `'/'`，
> 部署於子目錄請設為該子目錄路徑，或設為 `'./'` 使用相對路徑。

## 功能總覽

- **班表匯入**：支援點選或拖曳檔案；自動偵測格式（盤點行事曆勤務報表／舊版班表匯入檔），
  標題列位置與欄位皆動態辨識，未知欄位原樣保留
- **拖曳調移**：門市↔門市、人員↔人員互換；店暫存區與班表雙向拖曳（覆蓋時原門市自動退回）
- **就地編輯**：雙擊人員或門市即可修改；店號與店名雙向連動，查無門市時標紅提示
- **店暫存區**：手動新增或匯入店庫異動；可指定日期限制；隨捲軸固定
- **批次操作**：勾選多間門市一次移至暫存區；新增與刪除空白組別
- **自動對照**：由班表推導「代號↔工號」與「店號↔門市資料」，編輯時自動同步
- **當日出勤列**：依排班次數上色（無色未排班／淡藍休假／黃1間／綠2間／紅需留意）
- **自動警告**：休假衝突、同月重複盤點（僅提示不阻擋）
- **班表匯出**：格式完全還原，實測 397 筆逐格比對 0 差異

系統簡介

每月排定盤點班表時，需依門市狀況調整人員與門市的配對。原作業方式是直接在 Excel 中剪貼儲存格，一次調動往往牽涉多個欄位，容易錯位，也難以察覺「同一人被排太多間」「已排休假卻仍被排班」「同一間店重複盤點」等問題。

本系統將班表轉為卡片式介面，門市與人員可直接拖曳互換，系統並自動比對資料提出提醒。調整完成後匯出的 Excel 與原始檔案格式完全一致，可直接沿用既有流程。

不需安裝任何軟體 系統打包為單一 HTML 檔案，所有程式碼已內嵌其中。取得檔案後點兩下即可用瀏覽器開啟，不需要安裝、不需要帳號、不需要連網。

3. 帳號與登入

本系統不需要帳號，也沒有登入畫面 這是一套單機工具，取得檔案後直接開啟即可使用。因此不涉及帳號申請、密碼重設或帳號鎖定等程序。

3.1 開啟方式

  1. 取得檔案 盤點班表調移系統.html（由維護窗口提供）
  2. 將檔案存放於自己電腦的任一資料夾（建議放在桌面或固定的工作資料夾）
  3. 在檔案上點兩下，系統會以預設瀏覽器開啟
  4. 看到「尚未匯入班表」的畫面即代表開啟成功
建議使用 Chrome 或 Edge 請勿使用 Internet Explorer。若點兩下後開啟的是其他程式，請在檔案上按右鍵 →「開啟檔案」→ 選擇 Chrome 或 Edge。

3.2 取得最新版本

系統更新後會發送新的 HTML 檔案。新舊版本只要覆蓋原檔即可，不需要移轉任何設定或資料。可由畫面標題與檔名確認版本。

4. 功能操作說明

本章依實際操作順序說明。建議首次使用者依序閱讀 4.1 至 4.11。

4.1 匯入班表

用途：將盤點行事曆勤務報表載入系統，開始進行調移作業。

操作步驟

  1. 準備好報表檔案，檔名格式類似 INV_7_5盤點行事曆_勤務行事曆報表_20260824145408.xlsx
  2. 使用下列任一方式匯入：
    • 點擊左上角「匯入班表」按鈕，選擇檔案
    • 直接把檔案拖曳到畫面中央的虛線框，框線變色並顯示「放開以匯入班表」時放開滑鼠
  3. 匯入完成後，上方會出現日期列，下方顯示當日的組別卡片

系統會自動處理的事

項目說明
標題列位置報表前 6 列為標頭（盤點月份、部別、課別、店數），系統會自動找到第 7 列的欄位標題，不需事先刪除
欄位辨識依關鍵字比對，即使報表新增欄位也不會遺失，匯出時原樣保留
午別轉換報表中的「上／下」自動對應為上午／下午，匯出時還原
日期格式2026/08/03 於畫面顯示為「08/03 週一」，匯出時還原為原格式
組別劃分依檔案原始順序，將相鄰且帶隊者相同的列合併為一組
補齊午別報表只列出實際有安排的工作，若某組只有上午或只有下午，系統會補上空白槽位供調移使用
關於「序」欄位 報表中的「序」是整份檔案的流水號，與實際的分組順序無關（例如 08/03 的序是 7、11、8、14…）。系統一律依檔案原始的列順序顯示，不依序號排序，因為依序號排會把同組人員完全打散。匯出時序的數值保留原值不變動。
也支援舊版班表匯入檔 若匯入的是舊版「班表匯入_北一08-xxxx.xlsx」（午別為 1／2、每日固定 30 列），系統會自動辨識並以對應方式處理，不需切換任何設定。

4.3 拖曳調移

用途：本系統的核心功能，用滑鼠拖曳即可調換門市或人員。

拖曳來源拖到哪裡結果
門市卡片另一槽位的門市卡片兩邊門市資訊互換，人員不動
人員卡片另一槽位的人員卡片兩邊人員互換，門市不動
店暫存區的店槽位的門市卡片指派該店。若原本已有門市，原門市會退回暫存區
槽位的門市卡片店暫存區門市退回暫存區，該槽位清空

操作方式

  1. 將滑鼠移到卡片上，游標左側會出現拖曳握把
  2. 按住滑鼠左鍵不放，拖動到目標位置
  3. 目標區域會變成紫色底，表示可以放開
  4. 放開滑鼠完成調換
覆蓋不會遺失資料 從暫存區把店拖到已經有門市的槽位時，原本那間店不會消失，而是自動退回暫存區，並且插在你剛剛拖走那張卡片的位置，方便接續操作。
哪些欄位會跟著移動
分類欄位
門市店號、店名、型態、前次盤點、備註、課別、課別代號、營業課別
人員預定盤點者、人力、盤點1～8（工號）
固定不動序、午別、日期
備註記載的是門市的歸屬與限制（如「四課勿動」），因此隨門市移動；人力與盤點1～8 的工號對應人員，因此隨人員移動。

4.4 雙擊快速修改

用途：不必開啟編輯視窗，直接在卡片上修改門市或人員。這是最常用的修改方式。

修改人員

  1. 在人員文字上點兩下
  2. 文字變成輸入框並自動全選，直接輸入新的人員代號即可（例如「孟達姵」）
  3. 輸入過程下方會即時顯示人數與各代號，查不到工號者會標紅
  4. 按 Enter 儲存，按 Esc 取消，點到別處也會儲存
雙擊「吳羽」 ↓ [吳羽________] 2 人 吳 羽 Enter 儲存・Esc 取消
工號與人力會自動更新 儲存後系統會依新的人員自動重算「人力」與「盤點1～8」的工號，不需手動維護。例如改成「孟達姵慈」後，人力自動變為 4 人，工號同步為 10207006／10305002／11404004／11505004。

修改門市

  1. 在門市文字上點兩下
  2. 展開店號與店名兩個輸入框，兩者雙向連動：
    • 輸入店號 → 自動帶出店名、型態、課別、課別代號、營業課別
    • 輸入店名 → 自動帶出店號與其餘欄位（記不得店號時使用）
  3. 兩欄都有下拉建議清單，打幾個字就會列出符合的門市可直接挑選
  4. 按 Enter 或點「儲存」完成，按 Esc 取消
輸入不存在的門市會標紅提示 若輸入的店號或店名在系統中查不到，會顯示「查無此門市，連動欄位不會更新」，型態與營業課別維持原值不會被亂改。此時請自行確認欄位內容是否正確。
留空即清除 把店號與店名都清空後儲存，等於將該槽位的門市移除，人員仍會保留。

4.7 批次移動門市

用途：一次把多間門市移到暫存區，適合大幅調整當日班表時使用。

  1. 勾選各卡片左上角的核取方塊（沒有門市的槽位無法勾選）
  2. 畫面底部浮出操作列，顯示「已勾選 N 間門市」
  3. 點「移到暫存區」完成，或點「取消」放棄選取
已勾選 3 間門市　[移到暫存區]　[取消]
人員會保留在原位 批次移動只搬走門市，該槽位的人員仍留在原地。移到暫存區的門市會標記「原 MM/DD」作為參考，但不會限制只能放回那一天。

4.8 新增與刪除組別

用途：當日組數不足、無處安置從其他日期調來的門市時，可新增組別。

新增組別

  1. 捲動至組別卡片區最後，點擊虛線方塊「＋ 新增組別」
  2. 系統建立一組含空白上午與下午槽位的新組別
  3. 將門市拖入或雙擊填寫即可

刪除空白組別

  • 單組刪除：空白組別的標題右側會出現垃圾桶圖示，點擊即可刪除
  • 批次清除：空白組別達 2 個以上時，組別區下方會出現「清除空白組別（N）」，一次清光
不小心新增太多也不影響匯出 空白槽位（沒有門市也沒有人員）不會寫入匯出的 Excel。實測新增 10 組空白後，匯出仍為原本的 397 筆，完全不受影響。刪除功能只是為了讓畫面整齊。
有資料的組別不會出現刪除鈕 只有「門市與人員都空」的組別才可刪除。若某組已把門市移走但人員還在，不算空白組，不會被誤刪。

4.9 當日出勤檢視

用途：一眼看出當日每位人員被排了幾間店，及早發現排班過重或漏排。

顏色說明

顏色條件意義
無色0 次今日未排班
淡藍有休假且未被排班正常休假
黃色1 次今天帶 1 間店
綠色2 次今天帶 2 間店（常態）
紅色3 次以上，或有休假卻被排班需要留意
紅色是「提醒」不是「錯誤」 門市庫存較少時，一個人一天帶 3 間店是合理的安排。標紅只是讓你一眼看出誰今天帶得比較多，方便評估是否需要調整。

其他說明

  • 將滑鼠移到圓圈上，會顯示完整資訊，例如：劉育青（資深專員）・今日 2 次　休假中（特休）
  • 統計時只計算店號有填的槽位，避免備註列的文字被誤算為人員
  • 「預定盤點者」會逐字拆解，「于筱董」代表于、筱、董三個人，各計 1 次
  • 班表中出現但人員名單查不到的代號（例如新進人員尚未建檔），仍會照常顯示並計次，外框改為虛線
部分功能需 API 串接後才完整 「未排班（無色）」與「休假（淡藍）」需要人員通訊錄與休假資料才會出現。API 尚未串接前，出勤列只會顯示班表中實際出現過的人員代號。

4.10 自動警告

同月重複盤點

系統會掃描整份班表，找出被排定兩次以上的門市，以橘色橫幅列出：

同月重複盤點（2 間） 閉轉解續約等異動可能需要再盤一次，請確認是否為預期安排。 022620 新格致店　重複 2 次：[08/14 上午・家達瑄] [08/17 上午・絜筱于] 026254 教育大學店　重複 2 次：[08/15 上午・廷珊] [09/01 上午・董皓]
  • 日期標籤可以點擊，直接跳到那一天查看
  • 暫存區的卡片也會標示「已排 MM/DD」，拖曳之前就看得到
  • 拖曳當下另會顯示提示訊息
只警告，不阻擋 閉店、轉手、解約、續約等異動，確實可能需要同月再盤一次（例如已於 8/14 盤過，後續發文 8/17 解約）。因此系統會讓你正常操作，橫幅則持續提醒你確認。

休假衝突

當某人當日登記了休假、卻仍被排進班表，畫面上方會出現琥珀色橫幅：

⚠ 休假衝突（1 人） 劉育青（青）［特休］被排入 上午 雙林店、下午 建錦店

此功能需要人員通訊錄與休假資料都取得後才會啟用。

4.11 匯出 Excel

用途：把調整後的班表存回 Excel，格式與原始檔案完全一致。

  1. 點擊左上角「匯出 Excel」
  2. 瀏覽器下載檔案 盤點班表.xlsx
  3. 可直接沿用既有流程使用該檔案

匯出規則

項目處理方式
報表標頭前 6 列（盤點月份、部別、課別、店數）原樣還原
欄位順序完全比照匯入時的原始檔案
列的順序依畫面上的順序，即匯入時的檔案順序
序保留原值不重新編號（可能是來源系統的識別碼）
人力依預定盤點者的人數自動重算，不會殘留舊值
盤點1～8依人員對應的工號寫入
空白槽位門市與人員皆空者不寫入檔案
移走門市但人員仍在該列仍會輸出
格式還原經過驗證 以 397 筆的實際報表測試，匯入後直接匯出並逐格比對，結果與原始檔案完全一致（0 格差異），包含報表標頭、日期格式與午別寫法。

6. 常見問題 FAQ

Q1. 點兩下 HTML 檔案後畫面一片空白？

請確認開啟的是我們提供的單一 HTML 檔案（檔案較大，約 780 KB）。若是從程式資料夾中直接開啟 index.html（僅 1 KB），會因為沒有經過編譯而顯示空白。另請改用 Chrome 或 Edge 開啟。

Q2. 重新整理後資料都不見了？

這是正常設計。系統不會保存任何資料，重新整理或關閉瀏覽器後即清空，需重新匯入班表。這樣的設計可確保人員個資不會殘留在電腦上。調整完請記得先匯出 Excel。

Q3. 畫面上方顯示「人員資料 API 尚未連線」？

這是正常的提示，代表後端資料尚未串接。此時班表匯入、拖曳、編輯、匯出等功能皆可正常使用，僅人員姓名、休假標示與休假衝突警告需待串接後才會顯示。

Q4. 匯入後某一組只有上午，下午是空白的？

這是正常的。報表只列出實際有安排的工作，系統會自動補上空白槽位，讓你可以把其他日期的門市調移進來。這些空白槽位不會寫入匯出檔案。

Q5. 輸入店號後店名沒有跟著變？

請確認該店號是否存在於目前匯入的班表中。若是新開店、或其他月份的門市因閉轉解臨時排入，系統目前查不到該門市資料，會顯示「查無此門市」，此時需自行填寫欄位。待資訊部串接店鋪檔後即可自動帶入。

Q6. 不小心新增太多空白組別，會影響匯出嗎？

不會。空白槽位不會寫入匯出檔案。若想整理畫面，可點擊空白組別標題旁的垃圾桶圖示，或使用「清除空白組別」一次清除。

Q7. 為什麼同一間店出現重複盤點的警告？

系統偵測到該門市在同一份班表中被排定兩次以上。這不一定是錯誤——閉店、轉手、解約、續約等異動確實可能需要再盤一次。請確認是否為預期安排即可，系統不會阻擋你的操作。

Q8. 拖曳人員後，工號會跟著換嗎？

會。「人力」與「盤點1～8」的工號屬於人員資料，拖曳互換人員時會一併移動。手動修改人員後，系統也會自動重算工號與人力。

Q9. 備註為什麼跟著門市走，而不是跟著人？

備註記載的是門市的歸屬與限制（例如「四課勿動」「北二勿動」），屬於門市資料，因此隨門市移動。

Q10. 匯出的 Excel 開啟後亂碼？

系統匯出的是標準 .xlsx 格式，正常情況不會亂碼。若發生此狀況，請確認是以 Excel 開啟而非其他文字編輯器，並回報至維護窗口。

Q11. 系統可以多人同時使用嗎？

可以，但各自獨立作業。每個人開啟的是自己電腦上的檔案，資料不互通。若需要協作，請以匯出的 Excel 檔案交換。

Q12. 舊版的班表匯入檔還能用嗎？

可以。系統會自動辨識格式，舊版「班表匯入_北一08-xxxx.xlsx」（午別 1／2、每日 30 列）仍可正常匯入與匯出。

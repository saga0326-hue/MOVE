# 教學影片錄製

用 Playwright 自動操作系統並錄成教學影片。**系統改版後重跑一次就有新版影片**，不需要重新手動錄製。

---

## 怎麼跑

```bash
npm install
```

```bash
npx playwright install chromium
```

```bash
npm run record
```

產出在 `output/`：

| 檔案 | 內容 |
|---|---|
| `盤點班表調移系統_操作教學.webm` | 影片（約 6 分鐘，1440×810） |
| `frames/*.png` | 各段落截圖，可直接放進操作手冊 |
| `盤點班表.xlsx` | 腳本最後匯出的檔案，用來確認匯出真的成功 |

`.webm` 用 Chrome 或 Edge 直接開就能播。要放進 PowerPoint 或 LINE 再轉檔：

```bash
npm run mp4
```

轉檔需要系統裝有 ffmpeg（`winget install Gyan.FFmpeg`）。Playwright 內建的 ffmpeg 只有 WebM 編碼器，轉不了 mp4。

---

## 前置條件

1. **單檔版系統要先建好**——腳本錄的是 `dist-standalone/index.html`：

   ```bash
   npm run build:standalone
   ```

2. **要有班表檔案**。預設路徑寫在 `record.js` 最上面，可用環境變數覆寫：

   ```bash
   set TUT_XLSX=D:\某處\INV_7_5盤點行事曆_勤務行事曆報表_20260824145408.xlsx
   ```

> 影片會拍到班表內容（含人員代號與工號）。對外散布前請先確認範圍。
> `.gitignore` 已排除 `output/`，影片與匯出檔不會進版控。

## 檔案

| 檔案 | 用途 |
|---|---|
| `record.js` | 劇本與所有操作 |
| `overlay.js` | 疊加層：模擬游標、字幕、章節標籤、重點框、章節卡 |
| `to-mp4.js` | webm → mp4 |
| `debug-drag.js` | 拖曳出問題時的診斷腳本，會印出套件各階段的狀態 |

其他選項：

```bash
npm run record:headed
```

開一個看得見的視窗跑，方便看它到底點到哪裡。`TUT_SPEED=0.6` 可讓步調更緊湊。

## 改劇本要注意的三件事

### 1. 拖曳的來源與目標必須在同一排

`@hello-pangea/dnd` 在**靠近視窗上下緣 26% 的範圍會自動捲動畫面**。放置點落在那裡，拖到一半版面就位移，店會掉到別的槽位——曾經因此錄出「旁白說排到 08/06 下午、畫面其實掉到第 9 組上午」的影片。

`dragTo()` 已經會先把來源與目標的中點移到畫面正中央，並在放置點仍落在危險區時**直接中止**。但兩個目標若相隔超過一排就一定塞不進安全範圍，這時要改挑同一排的組別。

### 2. 每個動作都要驗證結果

`dragTo()` 的第四個參數是驗證函式，`expectText()` 與 `checkStore()` 也都會確認動作真的生效，不符就中止錄製。

**這不是多餘的保險**。拖曳失敗時畫面看起來完全正常，只是東西沒動——沒有驗證就會錄出一支旁白與畫面不符的教學片，而且不重看整支影片不會發現。

### 3. 旁白寫死的資料要跟著改

劇本引用了來源報表的實際內容（長慶店、龍昌店、台北地下街店、重慶店、羅安店，以及 `D_MAIN` 等日期常數）。換一份班表就要一起改，否則字幕會對不上畫面。

## 劇本大綱

| 段落 | 內容 |
|---|---|
| ① 匯入班表 | 匯入報表、說明 API 未連線的提示 |
| ② 畫面說明 | 日期列（週六綠／週日紅）、當日出勤配色、組別結構 |
| ③ 自動檢核 | 同月重複盤點、一天排 3 間店的紅圈、收合橫幅 |
| ④ 改午別 | 同一天上午與下午的店對調 |
| ⑤ 改日期 | 移到暫存區 → 切換日期 → 放進自動補出的空白槽位 |
| ⑥ 批次調移 | 勾選多間一次移到暫存區 |
| ⑦ 調整人員 | 拖曳互換、雙擊就地編輯 |
| ⑧ 就地編輯門市 | 店號店名雙向連動、重複盤點即時更新 |
| ⑨ 新增暫存店 | 打店名帶出店號、指定日期 |
| ⑩ 組別管理 | 新增組別、清除空白組別 |
| ⑪ 匯出 Excel | 序保留原值、人力重算、空白列不輸出 |
